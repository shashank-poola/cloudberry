Slack is useful for bringing team conversations, updates, and decisions into Cloudberry.

## Connect Slack

1. Open **Plugins** in Cloudberry.
2. Select **Slack**.
3. Complete the Slack authorization flow.
4. Return to Cloudberry and confirm that Slack shows **Connected** and **Events active**.

Only a workspace owner can start or manage the connection.

## What it receives

Cloudberry currently receives new Slack channel messages through configured Composio events. Human messages are included and bot messages are filtered to prevent loops.

After processing, the messages can contribute to:

- Chat answers;
- recent Cloudpedia updates; and
- project or decision context when the message contains enough information.

## Current limitations

- Cloudberry does not import all previous Slack history automatically.
- Cloudberry does not yet reply inside Slack.
- `@Cloudberry` mentions are not yet supported.

Use Cloudberry Chat in the dashboard when you want an answer today.

## Slack not updating

Check that the integration says **Events active**. If it says **Events not configured**, an owner should select **Retry**. Self-hosted teams should also confirm that the Composio webhook is public, uses HTTPS, and is configured with the correct signing secret.
