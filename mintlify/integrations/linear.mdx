---
title: Linear
description: Connect Linear issues and project activity to Cloudberry.
---

Linear brings issue and project context into Cloudberry so your team can ask about work, ownership, and decisions in one place.

## Connect Linear

1. Open **Plugins** in Cloudberry.
2. Select **Linear**.
3. Complete the Linear authorization flow.
4. Confirm the connection and event status.

A company deployment may need to choose the Linear team whose activity should be received. Ask your Cloudberry administrator if the team is not configured.

## What it receives

The current Linear setup can receive configured events for:

- comments;
- new issues; and
- updated issues.

Those events become company context for Chat and Cloudpedia.

## Current limitations

- Cloudberry does not import the complete Linear history automatically.
- Cloudberry does not yet answer as a Linear comment.
- A connected account can show **Events not configured** until the team and triggers are set up.

If that status appears, an organization owner should check the Linear team configuration and select **Retry** in **Plugins**.
