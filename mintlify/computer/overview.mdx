---
title: Computer
description: Understand Cloudberry's optional Prized computer resource.
---

Cloudberry can connect your organization to a Prized computer resource.

This is useful as a foundation for future Cloudberry workflows, but the current feature is focused on the computer's lifecycle and status.

## Available today

- Provision a computer for your organization.
- Wake the stored computer when it is paused or asleep.
- View its current status and safe metadata.
- Replace the stored resource if it no longer exists.

## Not available yet

Cloudberry does not currently provide:

- a remote terminal;
- command execution;
- file operations; or
- browser automation.

The Computer feature should not be described as an autonomous computer agent yet.

## Computer vs. Codex

Computer provisioning and Codex authorization are independent:

- Connecting Codex does not provision a Prized computer.
- Provisioning a Prized computer does not connect Codex.

See [Provisioning](/computer/provisioning) for the current setup flow.
