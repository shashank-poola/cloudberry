Most company knowledge is spread across chat messages, issue trackers, code reviews, and documents. Cloudberry connects those sources and makes the useful context easier to find.

## How it works

```text
Your tools → Cloudberry → company knowledge → answers and updates
```

Cloudberry receives useful updates from connected tools, organizes them by company, and makes them available in Chat and Cloudpedia.

## What it remembers

Cloudberry can build context around:

- people and who owns work;
- projects and initiatives;
- decisions and changes to decisions;
- tasks and issues;
- repositories; and
- pull requests and code changes.

Answers include source context when it is available, so your team can understand where an answer came from.

## What it is not

Cloudberry is not a replacement for Slack, Linear, GitHub, or your source-of-truth systems. Those tools still own the original messages, issues, and code.

Cloudberry is also not an autonomous browser agent today. The Computer feature currently handles provisioning and status for a Prized computer resource; it does not run commands or automate a browser.

## Current scope

Cloudberry currently supports:

- organization-scoped workspaces;
- knowledge-aware web chat;
- Slack, Linear, and GitHub event ingestion;
- Cloudpedia updates, projects, and decisions;
- Codex chat through OpenAI device authorization; and
- Prized computer provisioning and status.
