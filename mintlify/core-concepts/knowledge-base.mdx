---

Cloudberry's knowledge base is built from events that arrive from your connected tools.

## From tool to answer

1. A connected tool sends Cloudberry an update.
2. Cloudberry saves the update for your organization.
3. Cloudberry organizes the useful people, projects, tasks, decisions, and code context.
4. Chat searches that context before answering a question.
5. Cloudpedia shows a simple view of important updates.

## Workspace data

Knowledge is separated by organization. A user only searches the workspace they belong to, and Cloudberry does not let the browser choose another company's organization.

## Source context

Cloudberry keeps the original event identity and provider context with the knowledge it creates. Chat can use that context for citations and traceability.

## Included today

The current ingestion path is trigger-based. Cloudberry receives the events configured for each integration; it does not automatically import the complete history of every connected provider.

If you connect a provider and do not see older content immediately, that is expected with the current product scope.
